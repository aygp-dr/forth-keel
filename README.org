A Forth system built in three layers, each written on top of the one
below, and tested against a fixed oracle corpus of SICP programs. A
layer uses only the layer below it and its own earlier definitions.

* Layers

| Layer    | Written in              | Contents                                                            |
|----------+-------------------------+---------------------------------------------------------------------|
| keel     | host language (Rust, C) | 13 primitives and the inner interpreter                             |
| frames   | Forth                   | stack words, arithmetic, control flow, compiler, outer interpreter  |
| planking | Forth                   | tagged cells, pairs, symbols, closures, promises, Cheney GC, reader |

The keel provides exactly =@ ! sp@ rp@ 0= + nand exit key emit execute
um* um/mod=. =nand= is the only logical primitive: =invert=, =and=, =or=
and =negate= are all derived from it in Forth. =sp@= yields the address
holding the former top of stack, which is what makes =dup= definable as
=sp@ @=. Cells are at least 32 bits and the corpus assumes no more than
32, so results match on a 32-bit host.

* Gates

Every gate must come back with zero findings; there is no warning tier.

- =gmake test= — experiments and the sea-trials on gforth
- =gmake docs= — the docs gate, including its negative fixtures
- =gmake tangle= — regenerate the derived files from [[file:spec.org][spec.org]]
- =gmake tangle-check= — confirm the derived files match the spec
- =gmake all= — all of the above

On FreeBSD use =gmake=: these makefiles need GNU make. The gates also
need bash, gforth 0.7.3, Emacs, Python 3, and node for the Mermaid
check; =gmake tools= installs the pinned Mermaid parser.
