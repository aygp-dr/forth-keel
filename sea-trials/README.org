#+TITLE: Forth oracle corpus
#+STARTUP: showall

29 Forth programs with expected output generated by Gforth 0.7.3. An
implementation (WAForth, a Rust/WASM kernel, a ClojureScript kernel)
passes when its output for each program matches =tests/NNN-name.out=.

* Running

#+begin_src sh
./run.sh                                   # gforth against the stored outputs
./run.sh --impl 'node rforth.js {}'        # another implementation; {} is the test path
./run.sh --supports core,core-ext          # skip tests that need other wordsets
./run.sh --loose                           # ignore differences in runs of spaces and line ends
./run.sh sicp                              # only tests whose name contains "sicp"
./run.sh --layer 0                         # only layer-0 tests; prints pass counts per layer
./run.sh --lint                            # check the two header lines and that every .out exists
./run.sh --regen                           # rewrite every .out from --impl (default gforth)
#+end_src

The exit status is 0 when every test that ran passed. A failing test
prints the first 20 lines of a unified diff, expected (=-=) against
actual (=+=).

* Layout

| Range   | Layer                                   |
|---------+-----------------------------------------|
| 000-099 | kernel: stack, arithmetic, logic, memory, control, xt, does>, return stack |
| 100-199 | wordsets beyond core: strings, base, exceptions, floats, heap, locals |
| 200-299 | SICP chapter 1                          |
| 300-399 | SICP chapters 2 and 3                   |

Test numbers leave gaps so new tests can go between existing ones.

* Conventions every test follows

1. *Line 1 declares the wordsets used:* =\ requires: core core-ext=. The
   tags come from Gforth's =ans-report.fs=, with =block-ext= and =file=
   omitted (they appear only because of the =\= and =(= comment words)
   and with =f>s= / =s>f= counted as =float-ext= (Forth-2012).
2. *Line 2 declares the build layer:* =\ layer: 0= (frames words only),
   =\ layer: 1= (planking), or =\ layer: x= (wordsets outside the layered
   build: string, exception, float, memory, locals). Layer 0 and 1 tests
   gate milestones; layer x tests are reported only.
3. *No =bye= in the file.* The runner exits the system: Gforth gets
   =-e bye=, and another implementation's =--impl= command must exit
   after the file. A browser host can ignore this.
4. *Every value fits in 32 bits signed.* Results are the same on 32-bit
   (WAForth) and 64-bit (Gforth) cells. No test prints =1 cells=, an
   address, =here=, or =-1 u.=.
5. *Floats are printed as integers scaled by 10^6*, through
   =: f.6 1e6 f* fround f>s . ;=. Implementations format =f.= differently;
   =f.6= removes that difference.
6. *No =.s=.* Its format is implementation-specific. Tests print
   =depth .= or the values themselves.
7. *Labels before values*, e.g. =." swap: " 1 2 swap . . cr=, so a diff
   line identifies the word that broke.
8. *No redefinition warnings.* Names that collide with Gforth built-ins
   were renamed: =signum= (not =sign=), =my-const= (not =const=), =null=
   (not =nil=), =l-append= / =l-map= (Gforth defines =list-append= and
   =list-map=).
9. *Formatted with =tools/forthfmt.py=.* =tools/forthfmt.py --check sea-trials/tests/*.fs= exits 0.
10. *Double-cell results are printed as two cells* with =. .= (high cell
    first), so tests 010 and 110 need no DOUBLE wordset.

* Adding a test

1. Write =tests/NNN-name.fs= following the conventions above.
2. Run =python3 ../tools/forthfmt.py -w tests/NNN-name.fs=.
3. Find its wordsets: =gforth ans-report.fs tests/NNN-name.fs -e 'print-ans-report bye'=.
4. Generate the oracle: =./run.sh --regen NNN=.
5. Read =tests/NNN-name.out= and check every value by hand before
   committing. =--regen= records whatever Gforth printed, including
   wrong answers.
