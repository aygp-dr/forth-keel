# Resources

Run `scripts/pull-resources.sh` on a machine with general web access.
Git sources are cloned into `resources/vendor/<key>` at the commit pinned
in `spec.org`; web pages are saved as `resources/vendor/<key>.html`.
`resources/vendor/` is not tracked.

The table of sources, pins, and uses is in `spec.org`, section Resources.
