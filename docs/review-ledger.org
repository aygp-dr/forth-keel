#+TITLE: review ledger: reconcile at spec v0.2

Deviations declared while establishing forth-keel. Each entry is
reconciled at spec v0.2.

* 2026-11-15 — tooling language
- Deviation: =tools/forthfmt.py= and =gates/docs_gate.py= are Python;
  the house preference is Babashka.
- Why reality demanded it: the build cell could not install Babashka;
  Python 3 was available and could be run against gforth here.
- Target rule still stands: yes, tooling in the project's tool language.
- Reconcile: port both to Babashka, or record Python as the gate language.

* 2026-11-15 — experiment 001 runs frames on a host compiler
- Deviation: =experiments/001-frames-from-nand= uses gforth's =:=, =;=
  and number parser, and emulates =nand= as =and invert=.
- Why reality demanded it: there is no keel yet (M2); the data words can
  be checked on a host, control flow cannot.
- Target rule still stands: yes, frames use keel primitives only (R-F-01, R-F-02).
- Reconcile: re-run the same 432 checks on keel-rs at M3.
- Reconciled 2026-11-15 by experiment 008: the same 432 checks pass against
  the Rust keel, where =nand= is a real primitive rather than =and invert=,
  and the frames source now needs no number literal, so gforth's number
  parser is no longer borrowed either. Still outstanding from this entry:
  control flow, the return stack and the compiler, which is M3 proper.

* 2026-11-15 — sea-trials changed after the corpus tarball was sent
- Deviation: =sea-trials/= differs from =forth-oracle-corpus.tar.gz=:
  every test gained a =\ layer:= line; =010-arith= prints =um*= and
  =m*= results as two cells instead of =d.=; =110-base= dropped its =d.=
  line. Both now need no DOUBLE wordset and are layer 0.
- Why reality demanded it: layer tagging (R-T-01) and keeping =um*= /
  =um/mod= testable at layer 0, where they are keel primitives.
- Target rule still stands: yes, =.out= files are regenerated only for
  changed tests and checked by hand.
- Reconcile: treat =sea-trials/= in this repository as the corpus of
  record; discard the earlier tarball.

* 2026-11-15 — component documents not tangled from the spec
- Deviation: =sea-trials/README.org=, =experiments/README.md= and the
  experiment documents are written directly, not tangled.
- Why reality demanded it: they describe one component in detail;
  tangling them would move most of their text into =spec.org=.
- Target rule still stands: yes, no fact may appear in them that
  contradicts =spec.org=.
- Reconcile: decide at v0.2 whether =experiments/README.md= is tangled
  from the spec's Experiments table.

* 2026-11-15 — the keel lives in its own repository
- Deviation: the =* Scope= table gave the keel a =keel/= directory in
  this repository; it is now https://github.com/aygp-dr/keel-rs.
- Why reality demanded it: M2 (native, =cargo test=) and M4 (wasm32,
  wasm-bindgen) are two targets over one copy of the thirteen
  primitives. A cargo workspace holds both; a directory here would
  either duplicate the kernel or make this repository a Rust project.
- Consequence for the labels: =[E]= means "observed in this
  repository", so the 26 passing tests in =keel-rs= cannot mark R-K-01
  or R-K-04 as =[E]= here. Both stay =[H]= even though their tests pass,
  which understates what is known.
- Target rule still stands: yes, every keel requirement is decided by a
  per-primitive test, wherever that test lives.
- Reconcile: at v0.2 either define a label for evidence observed in a
  named sibling repository, or gate =keel-rs= from here so its result is
  observed in this repository.
